# ADR 0035: eza と bat の短いエイリアスを作る

ステータス: 採択→eza の表示のオプションはADR 0053

## 文脈

eza (`ls` の代わり) と bat (`cat` の代わり) は Nix で入れているが、エイリアスが無く、毎回 `eza`・`bat` と打っている。
短いエイリアスと、よく使う eza のオプションの組み合わせのエイリアスが欲しい。

- `zsh/aliases.sh` には `ls` のエイリアス (`la`・`lf`・`ll`・`llh`) があり、`g` (git)・`j` (jobs) のような 1 文字の
  エイリアスもある。
- `e`・`b`・`el`・`ea`・`ela`・`et` は、どれも今の zsh でコマンド・エイリアス・関数として使われていない。
- eza は `exa` という名前でも呼べる (eza のパッケージが互換のための `exa` を入れている) が、`exa` は開発が終わっているので、
  エイリアスは `eza` を直接呼ぶ。

## 実装すること

- `zsh/aliases.sh` に次のエイリアスを足す。

  | エイリアス | 中身 | 用途 |
  |---|---|---|
  | `e` | `eza` | 一覧 |
  | `el` | `eza -l` | 詳細表示 (権限・サイズ・更新日時) |
  | `ea` | `eza -a` | 隠しファイルを含める |
  | `ela` | `eza -la` | 隠しファイルを含めた詳細表示 |
  | `et` | `eza --tree` | ツリー表示 |
  | `b` | `bat` | ファイルの表示 |

- コマンドが入っているときだけ定義する (既存の `nvim` などと同じく `(( $+commands[eza] ))`・`(( $+commands[bat] ))` で囲む)。
- `docs/specifications.md` の zsh の節に、エイリアスを書く。

## 実装しないこと

- 既存の `ls` のエイリアス (`la`・`ll` など) の変更や、`ls`・`cat` 自体の置き換え。
- eza の表示のオプション (アイコン・git の状態・ディレクトリを先に並べるなど) を全エイリアスに付けること。
- `et` の深さの制限 (`--level`)。

## テスト設計

- 設定ファイルの変更のため、自動テストは書かない。
- 新しい zsh で、`alias e b el ea ela et` が上の表のとおりであることを確かめる。
- 既存の zsh のテスト (`zsh/tests/`) がすべて通ること。

## トレードオフ

- 1〜3 文字の短い名前を使うため、将来同じ名前のコマンドを入れたときに、エイリアスが優先されて隠れる。
- `et` は深さを制限しないため、大きなディレクトリでは出力が長くなる (必要なら `et -L 2` のように指定する)。
