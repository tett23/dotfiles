# ADR 0054: tmux で、ペインのプログラムから端末への制御の素通し (allow-passthrough) を有効にする

ステータス: 採択

## 文脈

tmux は、ペインのプログラムが出力した端末の制御 (エスケープシーケンス) を解釈し、自分で描き直して外側の端末 (Ghostty) に送る。
tmux が知らない制御 (画像の表示の Kitty graphics protocol など) は、外側の端末に届かない。

- tmux には、プログラムが「パススルー」の形 (`ESC Ptmux; … ESC \`) で包んだ制御を、そのまま外側の端末に送る機能がある。
  既定は無効 (`allow-passthrough off`。手元の tmux 3.7c で確認)。
- 値は `off`・`on` (表示中のペインからだけ通す)・`all` (表示していないペインからも通す)。
- nvim の画像表示のプラグインや、端末に画像を出すコマンドなどは、tmux の中ではパススルーで制御を送る。
- クリップボードへのコピー (OSC 52) は、すでに `set-clipboard on` で tmux が外側に伝えているので、この設定とは関係しない。

## 実装すること

- `tmux/tmux.conf` に `set -g allow-passthrough on` を足す (表示中のペインからだけ通す)。
- `docs/specifications.md` の tmux の節に書く。

## 実装しないこと

- `all` (表示していないペインからも通す) にすること。裏のペインの出力が、見ている画面に割り込むため。
- 画像を表示するプラグイン・コマンドの導入。

## テスト設計

- 設定ファイルの変更のため、自動テストは書かない。
- 別の tmux サーバーで設定を読み込み、`show -gv allow-passthrough` が `on` であること。
- 本人が、普段の tmux で設定を読み込み直し (`prefix + r`)、パススルーを使うもの (画像表示など) を使うときに表示されることを確かめる。

## トレードオフ

- 表示中のペインのプログラムは、tmux を通さずに Ghostty へ任意の制御を送れるようになる。信頼できない内容 (知らないファイルを
  `cat` するなど) を表示すると、その中の制御も Ghostty に届く (Ghostty が受け付ける範囲で、画面の表示や設定が変わりうる)。
- tmux を通さない制御は tmux の画面の管理の外になるので、ペインを切り替えたときなどに表示が残ることがある。
