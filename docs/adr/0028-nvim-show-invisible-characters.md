# ADR 0028: nvim で全角スペース・改行・すべての半角スペースを表示する

ステータス: 採択

## 文脈

nvim は `list` を有効にし、`listchars` でタブ (`>-`)・行末の空白 (`_`)・ノーブレークスペース (`+`) を表示している
(`nvim/lua/config/options.lua`)。これに加えて、全角スペース・改行・すべての半角スペースを表示したい。
タブも表示を続ける。

- 全角スペース (U+3000) は `listchars` の対象外のため、ハイライトで示すしかない。
- 改行 (`listchars` の `eol`) の色は `NonText` で、カラースキーム (monokai-pro.nvim の classic) では `#2d2a2e` と
  背景 `#272822` とほぼ同じ色になり、表示しても見えない。
- 空白類 (`space`・`tab`・`trail`・`nbsp`) の色は `Whitespace` で `#5b595c` (行番号と同じ色)。暗すぎて、
  すでに表示しているタブなどにも気づけなかった。

## 実装すること

- `nvim/lua/config/options.lua` の `listchars` に次を足す。既存の記号 (`tab:>-`、`trail:_`、`nbsp:+`) は変えない。

  | 項目 | 記号 | 対象 |
  |---|---|---|
  | `space` | `·` | すべての半角スペース |
  | `eol` | `↲` | 改行 |

- 全角スペースは、ハイライトグループ `ZenkakuSpace` を作り、各ウィンドウに `matchadd` で `\%u3000` を登録する
  (`VimEnter` と `WinNew` の autocmd。`options.lua` の隣の `nvim/lua/config/autocmds.lua` に置く)。
- 色は monokai-pro.nvim の `override` (ADR 0026 で `Visual` を上書きしている所) にまとめる。
  - `Whitespace` と `NonText` の文字色を `#919288` にする (テーマの classic パレットの `dimmed2`)。
    コメント (`#727072`) より明るく、本文 (`#fdfff1`) よりは暗い。改行の記号もこの色で見えるようになる。
  - `ZenkakuSpace` は背景色 `#919288` で塗る (全角スペースは記号を出せないため、文字幅いっぱいの背景で示す)。
  - 色の値は試用のうえで本人が変えることがある。値を変えるだけなら新しい ADR は作らない (ADR 0026 と同じ扱い)。
- `docs/specifications.md` の nvim の節に、表示する不可視文字を書く。

## 実装しないこと

- 不可視文字を表示するプラグイン (visual-whitespace.nvim など) の導入。
- 全角スペース以外の Unicode の空白 (U+2000〜U+200B など) の表示。
- ファイルの種類ごとに表示を切り替えること。

## テスト設計

- 設定ファイルの変更のため、自動テストは書かない。
- nvim をヘッドレスで起動し、次を確かめる。
  - `vim.o.listchars` が既存の項目に上の表の項目を足したものであること。
  - `nvim_get_hl` で `Whitespace`・`NonText` の文字色と `ZenkakuSpace` の背景色が `#919288` であること。
  - 全角スペースを含むバッファで `getmatches()` に `\%u3000` が登録されていること (新しいウィンドウを開いた後も)。
- 実際の見え方は本人が目で確かめる。

## トレードオフ

- すべての半角スペースに記号が付くため、画面の情報量が増える。インデントでは indent-blankline の線と記号が並ぶ。
- 不可視文字がコメントより明るくなり、目立つ。気づけることを優先した。
- `NonText` は改行の記号のほかに、折り返しの記号 (`showbreak`) などにも使われる。これらも少し目立つようになる
  (バッファ末尾の `~` はテーマが `EndOfBuffer` を別に定義しているため変わらない)。
- 独自の設定 (autocmd とハイライト) が増える。
