# ADR 0120: elan を Nix の CLI 一覧に加える

ステータス: 採択

## 文脈

依存一覧に elan を追加する依頼があった。

## 調査した事項

[dependencies.md](../../dependencies.md) は Nix で管理するコマンドを「Install CLIs」に列挙している。
[ADR 0013](0013-generate-config-from-dependencies-with-claude.md) は、この一覧を設定の生成元と定めている。

## 実装すること

`dependencies.md` の「Install CLIs」に `elan` を加える。
`flake.nix` の `home.packages` に `pkgs.elan` を加える。

## 実装しないこと

Lean の既定のツールチェーンの指定は対象外とする。

## 不変条件

なし。依存一覧の項目だけを決めるため。

## テスト設計

`dependencies.md` の差分を確認し、「Install CLIs」のコマンド列に `elan` が一度だけ現れることを確かめる。
`nix build .#darwinConfigurations.dione.system` を実行し、ビルド結果の依存に elan が含まれることを確かめる。

## トレードオフ

一覧への追加だけでは elan を利用できない。利用するには Nix 設定の同期と適用が要る。

## 参考文献

なし。
