# ADR 0022: send-to-kindle で .env のパスをオプションで指定できるようにする

- Status: Accepted
- Date: 2026-10-09

## Context

ADR 0021 で、send-to-kindle はカレントディレクトリの `.env`、無ければ環境変数から設定を読むようにした。
`.env` を別の場所 (例: `~/.config/send-to-kindle/.env`) に置いて、どのディレクトリからでも使いたい。

## Decision

- オプション `--env-file <パス>` (短縮形 `-e`、`--env-file=<パス>` も可) で、設定を読むファイルを指定できるようにする。
  - 指定したときは、そのファイルから読む。ファイルが無ければエラーにする
    (指定したのに環境変数へ黙って切り替わると、指定の誤りに気づけないため)。
  - 指定しないときは従来どおり、カレントディレクトリの `.env`、無ければ環境変数から読む。
- 設定が足りないときのエラーメッセージには、読んだファイルのパスを出す (既定は `.env`)。
- 引数の解釈 (`args.ts`) も純粋な関数として分け、`deno test` でテストする。

## Consequences

- `.env` をどこに置いても使える。オプションを付けない場合の挙動は変わらない。
