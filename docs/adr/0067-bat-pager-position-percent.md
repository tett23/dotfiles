# ADR 0067: bat のページャーに、今読んでいる位置 (全体の何 %) を出す

ステータス: 採択

## 文脈

本人から、bat で読んでいるときに、今の位置が全体の何 % かを出したいと要望があった。

- bat は、出力が端末の画面に収まらないとき、ページャー (less) に渡して表示する。ページャーは、`BAT_PAGER`・bat の設定の `--pager`・
  `PAGER` の順に決まる。今は `bat/config` に `--pager` が無く、`PAGER` は nix-darwin の既定の `less -R` なので、`less -R` で表示している。
  `MANPAGER` も bat を通す ([ADR 0053](0053-bat-manpager-and-eza-options.md)) ので、`man` も同じページャーで表示する。
- less (macOS の 668) の画面の下の表示は、既定では `:` だけ。`-M` (長い表示) にすると、表示している行の範囲・全体の行数・全体の何 % かを出す。
- ただし、bat は less にパイプで渡すので、less は最後まで読むまで全体の大きさが分からず、% を出せない。
  less の `--file-size` は、開いた直後に入力を最後まで読んで大きさを確かめる (パイプのときは遅くなりうるので既定では行わない)。
- 別の tmux サーバーで試した。`bat --pager='less -R --file-size -M' docs/specifications.md` で 1 画面進めると、下に
  `lines 20-38/410 7%` と出た。`man less` でも `line 1/1967 1%` と出た。`less -R` のままでは `:` だけだった。

## 実装すること

- `bat/config` に `--pager="less -R --file-size -M"` を足す (今の `less -R` に、位置の表示に要るものだけを足す)。
- `docs/specifications.md` の bat の記述に書く。

## 実装しないこと

- `PAGER`・`LESS` の環境変数を変えること (bat 以外の less の使い方 (`git` の delta など) は変えない)。
- less の下の表示を `-P` で独自の形にすること (`-M` の既定の形を使う)。
- 画面に収まるときにページャーを使わない `-F` を足すこと (今の挙動を変えない)。

## テスト設計

- 設定の値の変更のため、自動テストは書かない。次を確かめる。
  - `bat --diagnostic` (または `bat --config-file` の中身) で、ページャーが `less -R --file-size -M` になっていること。
  - 別の tmux サーバーで、`bat` で長いファイルを開いて 1 画面進め、下に `lines …/… …%` が出ること。`man` でも % が出ること。
  - 色 (`-R`) が今までどおり付くこと。
- 実際の見え方は本人が確かめる。

## トレードオフ

- `--file-size` のため、less は表示の前に入力を最後まで読む。とても大きいファイル・長い出力では、最初の画面が出るまで遅くなる
  (bat がファイル全体に色を付け終わるまで待つ)。
- 下の表示が `:` から `lines 20-38/410 7%` の形になり、少し長くなる。
