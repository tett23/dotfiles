# ADR 0089: nvim の `;` と `:` の入れ替えをやめ、既定の動きに戻す

ステータス: 採択

## 文脈

本人から、nvim の `;` と `:` の入れ替えをやめて、元に戻したいと要望があった。

- 今は、`nvim/lua/config/keymaps.lua` で `;` と `:` を入れ替えている (`map("", ";", ":")`・`map("", ":", ";")`。ノーマル・ビジュアル・
  オペレータ待ちのモード)。旧 `vim/keymap.vim` の `noremap ; :`・`noremap : ;` を移したもので、ADR は無く、`docs/specifications.md` にも書いていない。
  headless の nvim で `;` を押すと、コマンドラインに入る (`mode=c`) ことを確かめた。
- nvim の既定では、`:` でコマンドラインに入り、`;` は直前の `f`・`F`・`t`・`T` を同じ向きに繰り返す (`,` は逆向き)。
- flash.nvim の文字の移動 (`char` のモード) は、`f`・`F`・`t`・`T`・`;`・`,` を割り当てる。ただし、`;`・`,` は、すでにほかの割り当てが
  あるときは割り当てない (`lua/flash/plugins/char.lua`)。今は `;` に `:` を割り当てているので、flash は `;` を使わない。
  入れ替えをやめると、`;`・`,` は flash の繰り返しになる (flash の文字の移動が有効なとき。無効なら nvim の既定の繰り返し)。
- VSCode の vim の設定 (`vscode/settings.json`) と zsh の vi モードでは、入れ替えていない。

## 実装すること

- `nvim/lua/config/keymaps.lua` から、`;` と `:` を入れ替える 2 行と、その注釈を消す。
- `docs/specifications.md` の nvim の節に、`;`・`:` は nvim の既定のまま (入れ替えない) と書く。

## 実装しないこと

- `;` に、ほかの動き (コマンドラインなど) を割り当てること。
- flash.nvim の設定の変更。
- ほかのエディタ (VSCode など) の設定の変更。

## テスト設計

nvim のキーの割り当ての変更のため、CI の自動テストは書かない。実装の前に次を実行して、今の動きを確かめ (失敗を確かめ)、実装の後にもう一度実行して確かめる。

- `nvim --headless` で、ノーマルモードの `;` と `:` の割り当て (`maparg`) が無いこと (今は `;` → `:`、`:` → `;`)。
- `nvim --headless` で、`:` を押すとコマンドラインに入ること (`mode=c`)。
- `nvim --headless` で、`fa` の後に `;` を押すと、次の `a` に移ること (行 `xaxaxa` の先頭から `fa;` でカーソルが 3 文字目 (0 から数えて 3) に来る)。
- 本人が確かめる: nvim で `:` でコマンドラインに入り、`f<文字>` の後の `;`・`,` で繰り返せること。

## トレードオフ

- 長く使ってきた入れ替えをやめるので、慣れるまで `;` でコマンドラインに入ろうとして、`f`・`t` の繰り返しになることがある。
- コマンドラインに入るのに、Shift を押す (`:`) 必要がある。
