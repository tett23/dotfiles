# ADR 0026: nvim の選択範囲の背景色を monokai-pro.nvim の設定で上書きする

ステータス: 採択

## 文脈

nvim のカラースキームは monokai-pro.nvim の `classic` フィルタを使っている (ADR 0009)。
このテーマは選択範囲 (`Visual`) の背景を、文字色 `#c0c1b5` を背景色 `#272822` に 15% 混ぜた色 (約 `#3e3f38`) にしている。
背景との差が小さく、選択範囲が見分けにくい。

独自の設定はなるべく書かない方針のため、最初はテーマの乗り換えを検討した。しかし、Monokai 系の sonokai も
選択範囲のコントラストが十分ではなかった。テーマはそのままにし、選択範囲の色だけを上書きする。

## 実装すること

- `nvim/lua/plugins/colorscheme.lua` の `require("monokai-pro").setup()` に `override` を足し、
  `Visual` の背景色を `#55564e` にする。
  - テーマと同じ作り方 (文字色 `#c0c1b5` を背景色に混ぜる) で、混ぜる割合を 15% から 30% に上げた色。
    Monokai の灰色がかった雰囲気を保ったまま、選択範囲が見分けられる。
  - 最初の候補は紫寄りの `#5c4a6e` だったが、試した結果 `#55564e` にした。
  - `VisualNOS` はテーマ側で `Visual` へのリンクになっているため、追加の指定は要らない。
- 色は試用のうえで本人が変えることがある。値を変えるだけなら新しい ADR は作らない (色の値は仕様ではなく好みの調整とする)。
- `docs/specifications.md` に、選択範囲の色を上書きしていることを書く。

## 実装しないこと

- カラースキームの変更 (sonokai などへの乗り換え)。
- `Visual` 以外のハイライト (検索結果の `Search`、カーソル行の `CursorLine` など) の変更。
- テーマのパレット (`override_palette`) やスキーム (`override_scheme`) の変更。選択範囲以外の色に影響するため。

## テスト設計

- 設定ファイルの変更のため、自動テストは書かない。
- nvim をヘッドレスで起動し、`nvim_get_hl(0, { name = "Visual" })` の背景色が `#55564e` であることを確かめる。
- 実際に nvim でビジュアルモードの選択範囲が見分けやすいかは、本人が目で確かめる。

## トレードオフ

- 独自の設定が 1 か所増える。テーマを更新して `Visual` の扱いが変わっても、上書きが優先される。
- 灰色のため、紫寄りの色などに比べると目立ち方は控えめ。足りなければ値を変える。
