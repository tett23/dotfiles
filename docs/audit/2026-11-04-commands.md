# コマンドの監査 (2026-11-04)

dotfiles のスクリプトとシェルの関数・エイリアスが使っているコマンドについて、ベストプラクティスに沿っていないもの、古いコマンドや
古い出力の形に頼っているものを調べた。対象は `bin/`・`install.sh`・`bootstrap.sh`・`tmux/scripts/`・`tmux/*.conf`・`zsh/`・`git/config` の
エイリアス・`.githooks/`。手元の版は git 2.55.0、Docker 29.8.1、tmux 3.7c、Claude Code の CLI、codex-cli 0.162.1、yarn 4.18.1。

## 壊れている、または壊れうるもの

| ID | 場所 | 内容 | 直し方 |
|---|---|---|---|
| K1 | `zsh/fzf.sh` の `__docker_image_id`・`__docker_remove_image` | `docker images` の 3 列目をイメージの ID として使っている。Docker 29 で `docker images` の出力の形が変わり (`IMAGE  ID  DISK USAGE  CONTENT SIZE  EXTRA`)、3 列目は大きさになった。`__docker_remove_image` は大きさの文字列を `docker rmi --force` に渡す | `docker image ls --format` で列を決めて出し、ID を取る |
| K2 | `git/config` の `delete-merged-branches` | `git branch --merged` の表示用の出力を `grep`・`xargs` で加工している。ほかの worktree で使っているブランチ (`+` が付く) を除いていないので、そのブランチの削除でエラーになる | `git branch --merged --format` で、名前と worktree のパスを出し、今のブランチと worktree で使っているものを除く |
| K3 | `zsh/fzf.sh` の `__fbr` | `git branch --all --color` の表示用の出力を `sed` で加工している (表示の形は変わりうる)。`origin/HEAD` を `grep -v HEAD` で除くので、名前に `HEAD` を含むブランチも消える | `git for-each-ref --format` で名前を出す |

## 古いコマンド・ベストプラクティスに沿っていないもの

| ID | 場所 | 内容 | 直し方 |
|---|---|---|---|
| O1 | `git/config` の `co`・`cob` | `git checkout`・`git checkout -b`。git 2.23 からは、ブランチの切り替えは `git switch` (ファイルを戻すのは `git restore`) に分かれている | `switch`・`switch -c` にする (エイリアスの名前は変えない) |
| O2 | `tmux/statuses.conf` の `whoami` | ステータスラインの更新のたび (2 秒ごと) に `whoami` を起動する。tmux 3.x は書式 `#{user}` でユーザー名を出せる | `#{user}@#h` にする |
| O3 | `bootstrap.sh` | Nix のインストーラ (Determinate Systems) を v3.23.1 に固定している。最新は v3.24.1 | 固定の版を上げる |
| O4 | `zsh/fzf.sh` の `__fkill`・`__find_pid`・`__docker_stop_container`・`__docker_remove_image` | `[ "x$pid" != "x" ]` (昔のシェルのための書き方)、`echo $pid | xargs kill`、`local` の無い変数 (`__find_pid` の `pid`)、`_fzf_run` を通さない `fzf` の呼び出しが混ざっている | `[[ -n $pid ]]`・`local`・`_fzf_run` に揃える |
| O5 | `zsh/aliases.sh` | 使われていないエイリアス。`sed="gsed"` (`gsed` が無い。GNU の sed は Nix が `sed` の名前で入れる)、`diff='colordiff -u'` (`colordiff` が無い)、`python="python3"` (mise の Python が `python` を持つ) | 消す |
| O6 | `zsh/langs/go.sh` | `GOPATH` を ghq のルート (`~/repositories`) にしている。Go のモジュールのキャッシュ (`pkg/mod`) と `go install` のバイナリ (`bin/`) が `~/repositories` に入る。今の Go は `GOPATH` を設定しなくても動く (既定は `~/go`) | 要判断 (変えると、`go install` で入れたものの置き場所が変わる) |
| O7 | `bin/orch` の `cleanup` | worktree の削除に失敗したときの `rm -rf` の後に `git worktree prune` をしない (git に worktree の記録が残る)。`tmux kill-window -t "$role"` は名前で探すので、ほかのセッションの同じ名前のウィンドウを閉じうる | `git worktree prune` を足す。ウィンドウはセッションを付けて指定する |

## 問題が無かったもの

- `install.sh`・`bootstrap.sh`: POSIX sh・bash 3.2 で動く書き方で、`curl` のオプションも今の推奨どおり。
- `bin/update-nix`: `nix flake update --flake` (今の書き方)。`bin/update-mise`: `mise upgrade --yes`・`mise prune --yes`。
- `bin/sync-deps`: `claude -p` の `--allowedTools`・`--disallowedTools`・`--permission-mode` は、今の Claude Code の CLI にある。
- `bin/orch`: `codex exec` の `-C`・`--output-last-message`・`--sandbox` は、今の codex-cli にある。モデルの別名は今のモデル (Opus 5.5・Sonnet 5.5・Haiku 5.5・Fable 5.1)。
- `__yarn_workspaces`: Yarn 4 の `yarn workspaces list --json`。
- `tmux/tmux.conf`: tmux 3.7c の書き方。
- `tmux/scripts/lan-ip`: macOS の `route -n get default`・`ipconfig getifaddr`。
