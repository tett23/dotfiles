# Nix common dependencies

Nix flakesで依存を管理します。home-managerで永続化してください。
system aarch64-darwin で生成してください。
hostname は dione にしてください。

## Install CLIs

以下のコマンドをインストールしてください。
sed, awk, makeはGNUのものを利用してください。

claude-code git curl fzf ghq tmux nvim direnv jq eza bat fd rg mise awscli sed awk make sqlite gh

## Install Casks

以下のアプリケーションをnix-darwin経由でインストールしてください

aquaskk docker ghostty claude
